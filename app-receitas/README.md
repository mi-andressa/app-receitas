# 🍽️ Buscador Inteligente de Receitas

Projeto desenvolvido como requisito para a **Atividade Avaliativa 04** da disciplina de Desenvolvimento Web Front End do curso de Análise e Desenvolvimento de Sistemas (IFSP).

**Autora:** Mirela Andressa de Oliveira

## 📌 Sobre o Projeto
Esta aplicação é um buscador interativo de receitas focado em opções práticas de refeições (como frango, carnes, massas e low-carb). O projeto consome uma API Web para listar os pratos de forma dinâmica e apresenta os detalhes de cada receita (ingredientes e modo de preparação) através de uma janela Modal interativa, garantindo uma boa experiência ao utilizador e originalidade na proposta.

## 🚀 Tecnologias e Bibliotecas Instaladas
A aplicação foi construída utilizando o ecossistema moderno do React:
- **[React JS](https://react.dev/):** Biblioteca principal para a construção da interface de utilizador, utilizando Hooks (`useState`, `useEffect`) para gestão de estado e ciclo de vida.
- **[Vite](https://vitejs.dev/):** Ferramenta de build e servidor de desenvolvimento ultrarrápido.
- **Fetch API:** Utilizada de forma nativa para o consumo assíncrono dos dados da API Web (formato JSON).

## 📦 Como executar o projeto localmente

Para testares a aplicação na tua máquina, segue os passos abaixo. 

> **Nota:** A pasta `node_modules` não foi incluída neste repositório por uma questão de boas práticas de versionamento. É necessário instalar as dependências antes de rodar.

1. Clona este repositório:
\`\`\`bash

\`\`\`

2. Acede à pasta do projeto:
\`\`\`bash
cd app-receitas
\`\`\`

3. Instala as dependências necessárias:
\`\`\`bash
npm install
\`\`\`

4. Inicia o servidor de desenvolvimento
